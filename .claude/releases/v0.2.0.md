# CC DiskSage 0.2.0

本版把「空间分析」和「可清理项」连接起来，并为仪表盘大文件增加了 AI 元数据分析与回收站操作。

## 新增

### 仪表盘可清理摘要

- 快速扫描/管理员扫描完成后，仪表盘显示上次扫描的安全项与谨慎项大小、数量和时间。
- 新增「去清理建议」按钮，直接跳转到规则清理页。
- 明确提示全盘扫描只做空间分析，不会直接删除文件。

### 大文件操作

- 大文件列表支持展开全部条目。
- 每个大文件可以：
  - **AI 分析**：只发送脱敏元数据，发送前展示完整 payload 并要求同意；
  - **打开目录**：在资源管理器中定位文件；
  - **移到回收站**：逐项二次确认，只进入回收站。
- 后端只接受快照 ID + 文件索引，重新解析并校验路径；Windows、Program Files、
  Program Files (x86)、ProgramData 中的文件会被拒绝。
- 删除成功后从快照移除并持久化，仪表盘大文件列表和可用空间即时更新。

### AI 分析边界

- 默认发送：脱敏目录模板（文件名为 `<file>`）、分配/逻辑大小、修改日期、扩展名、
  本地证据 E1–E5。
- 默认不发送文件名；需要更准确判断时在设置中开启「发送样本文件名」。
- 不发送文件内容、哈希或同目录其他文件。
- AI 只给建议，不能新增候选、勾选或删除；删除按钮与 AI 结论独立，仍由用户确认。

## 升级

覆盖安装到原目录即可，数据目录和历史记录保持不变：

```powershell
Start-Process .\cc-disksage-0.2.0-offline-setup.exe -ArgumentList '/S','/D=D:\CCDiskSage' -Wait
```

## 校验

安装包 SHA-256 见附件 `SHA256SUMS.txt`。安装包仍未签名，SmartScreen 可能提示。
