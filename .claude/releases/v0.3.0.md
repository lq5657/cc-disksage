# CC DiskSage 0.3.0

本版集中解决两类问题：受限环境下的管理员功能可用性，以及扫描/清理深度。

## 提权兼容

- 保留 PowerShell 作为主路径；PowerShell 不存在、无法创建或在 UAC 前失败时，
  自动回退到原生 `ShellExecuteExW("runas")`。
- 当前进程已提权时直接启动 helper，不再经过 PowerShell。
- 取消 UAC 不会重试，避免连续弹两次授权框。
- helper 服务控制优先 PowerShell，失败时回退 SCM API；
  回收站清空优先 `Clear-RecycleBin`，失败时回退 `SHEmptyRecycleBinW`。
- 新增 `<数据目录>\logs\helper-launch.jsonl`，记录实际提权方式与失败原因。
- 适用场景：Windows 10 等禁用/移除 PowerShell 的环境。

## 深度清理规则

新增 12 条规则，并补充 positive/redline fixture：

- Edge/Chrome 组件与扩展 CRX 缓存
- Edge/Chrome GPU、Dawn 与着色器缓存
- Windows 维护/更新日志（CBS、DISM、WindowsUpdate、MoSetup、SIH、
  waasmedic、PITR、NetSetup、WinREAgent、USOShared）
- Prefetch、Panther、LiveKernelReports、Windows SystemTemp
- Microsoft Office 缓存（SolutionPackages、WebServiceCache、SmartLookupCache、
  OTele、OneNote cache）
- OneDrive 日志与遥测缓存
- Windows 升级残留（仅引导 cleanmgr，不直接删除）

真机实测新增可见可清理量约 1.5 GB（含 Office 532.7 MB、浏览器组件缓存约 255 MB、
Windows 维护日志约 662 MB、OneDrive 11.7 MB 等，具体以本机扫描为准）。

安全边界保持不变：不删除 WinSxS、Windows\Installer、WindowsApps、
System Volume Information、浏览器凭据、聊天数据库/媒体、pagefile/hiberfil；
管理员/谨慎项默认不勾选；永久删除仍需单独开关与二次确认。

## Treemap 深度下钻

- 完整扫描树压缩保存到 `<数据目录>\scans\<id>.json.gz`，保留最近 5 份。
- 点击目录按需加载下一层，每层最多 200 个目录，支持不限层级下钻。
- 历史扫描若只有 3 层摘要，会提示重新扫描，不再静默截断。
- 扫描/重启后仍可继续下钻（sidecar 保留范围内）。

## 只读深度发现

- 新增「深度发现」页，只读扫描所选卷：
  - 大文件 ≥100 MB
  - 日志/ETL ≥50 MB
  - 转储 ≥50 MB
  - 安装包/压缩包 ≥100 MB 且超过 180 天
- 跳过 WinSxS、Installer、System32、Program Files、reparse point、
  聊天数据目录等受保护位置。
- 只展示路径、大小、修改时间与分类；只能打开所在目录，没有删除入口。
- 支持实时进度与取消。

## 升级

覆盖安装到原目录即可，数据目录、历史与扫描结果保持不变：

```powershell
Start-Process .\cc-disksage-0.3.0-offline-setup.exe -ArgumentList '/S','/D=D:\CCDiskSage' -Wait
```

## 校验

安装包 SHA-256 见附件 `SHA256SUMS.txt`。安装包仍未签名，SmartScreen 可能提示。

## 已知限制

- 禁用 PowerShell 的 Windows 10 环境建议先验证管理员扫描/清理与回收站回退路径。
- 深度发现为只读结果，不会持久化；重启后需重新扫描。
- 超过最近 5 次扫描的 treemap 只能回退到 3 层摘要。
- 自动更新尚未实现。
