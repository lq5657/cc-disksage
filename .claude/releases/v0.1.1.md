# CC DiskSage 0.1.1

0.1.0 的清理体验修复版：更快的删除、实时进度、明确的管理员扫描入口。

## 修复与改进

### 清理速度

- 回收站删除改为批量提交（每批 256 个文件），避免为每个文件重复创建 COM/IFileOperation。
- 确认页新增「永久删除可重建缓存（更快，不进入回收站）」选项：
  - 只对安全/谨慎、可重建、非管理员的缓存项开放；
  - 需要单独勾选，并再次确认「无法通过回收站恢复」；
  - 默认仍为回收站，不改变原有安全默认。
- 400 个 fixture 文件实测：回收站清理约 1.5 秒；永久删除即时完成。

### 清理进度

- 清理计划执行时实时显示：已处理/总文件数、已处理字节、删除/失败数、当前路径、耗时。
- 管理员阶段显示「等待管理员授权/执行系统项」，系统引导与回收站清空阶段也有对应提示。

### 管理员扫描入口

- 清理建议页新增「管理员扫描」按钮：请求一次 UAC，通过 `disksage-helper.exe`
  只读扫描 Windows Temp、WER、更新缓存、传递优化等系统项，回填实测大小。
  取消 UAC 会保留普通扫描结果。
- 仪表盘原「MFT 秒扫」改名为「管理员全盘扫描」，明确这是需要 UAC 的全盘入口。
- 管理员项现在区分「待管理员扫描」与「管理员实测」，不再把估算值标成已实测。

## 升级

直接覆盖安装到原目录即可，数据目录与历史记录保持不变：

```powershell
Start-Process .\cc-disksage-0.1.1-offline-setup.exe -ArgumentList '/S','/D=D:\CCDiskSage' -Wait
```

## 校验

安装包 SHA-256 见附件 `SHA256SUMS.txt`。安装包仍未签名，SmartScreen 可能提示。
