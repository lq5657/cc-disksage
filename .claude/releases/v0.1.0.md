# CC DiskSage 0.1.0

首个可用版本：离线优先、规则驱动、证据优先的 Windows 磁盘清理工具。

## 下载

| 文件 | 大小 | 适用场景 |
|---|---|---|
| `cc-disksage-0.1.0-offline-setup.exe` | 约 212 MB | 断网 / 干净 Windows 10；内置 WebView2 离线安装器 |
| `cc-disksage-0.1.0-lite-setup.exe` | 约 4.9 MB | 已安装 WebView2 的 Windows 11 / 企业环境 |
| `SHA256SUMS.txt` | — | 两个安装包的 SHA-256 |

安装无需管理员权限。管理员清理项执行时会单独弹出 UAC。

## 主要功能

- 全盘只读扫描、ECharts treemap 空间分析、Top 目录与大文件
- NTFS MFT 秒扫（UAC 提权 helper，只读）
- TOML 规则引擎、路径安全、红线校验、E1–E8 证据链
- 快速扫描可清理项 → 计划预览 → 回收站删除 → 本地审计
- 管理员清理：Windows Temp、机器级 WER、Minidump、传递优化、Windows Update 缓存、
  DISM Analyze / StartComponentCleanup、休眠文件
- 系统引导：Windows.old、还原点、分页文件；回收站清空
- 重复文件查找与回收站删除（至少保留一个副本）
- 定时 / 低空间自动清理（仅安全、默认勾选、可重建、非管理员规则）
- 可选 OpenAI 兼容 LLM 标注（默认关闭，payload 预览与脱敏，不能新增删除动作）
- SQLite 持久化：扫描摘要、重复文件结果、扫描历史，保留最近 20 次
- 数据目录跟随安装盘：D 盘安装使用 `D:\CCDiskSageData\<用户名>`，自动迁移旧 C 盘数据
- 系统托盘：关闭窗口隐藏到托盘，扫描/清理等操作完成时发送 Windows 通知

## 系统要求

- Windows 11 x64；Windows 10 22H2 x64 尽力支持
- 安装包自带 WebView2 离线安装器（offline 版）
- 安装包未签名，SmartScreen 可能提示；可选择「更多信息」→「仍要运行」

## 安全说明

- 默认删除到回收站；永久删除需要单独开关与二次确认
- 永不清理 WinSxS、Windows\Installer、WindowsApps、System Volume Information、
  pagefile/hiberfil/swapfile、注册表 hive、浏览器凭据、聊天数据库/媒体
- 永不跟随 reparse point / junction / symlink
- 前端 IPC 只接受 finding / plan / 重复文件 ID，不接受任意删除路径
- 管理员动作只走 `disksage-helper.exe`，UI 始终 `asInvoker`
- 无遥测；LLM 可选，只发送脱敏聚合元数据，不发送文件内容

## 已知限制

- 未做代码签名
- 自动更新未实现
- 计划任务 `--auto-clean` 无窗口运行，不弹托盘通知，只写自动清理日志
- MFT 扫描仅支持 NTFS；重复文件默认只扫描文档/下载/图片/视频/桌面
- 干净 Windows 10 断网安装与部分系统引导项交互仍待 VM 验证

## 校验

安装包 SHA-256 见附件 `SHA256SUMS.txt`。
